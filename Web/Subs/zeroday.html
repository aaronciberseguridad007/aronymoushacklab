01. 🧠 INTRODUCCIÓN

Un zero-day es una vulnerabilidad desconocida por el fabricante que puede ser explotada antes de que exista un parche.

🔗 Leer más: OWASP Vulnerabilities

02. 📌 DEFINICIÓN

Un zero-day exploit ocurre cuando un atacante utiliza una vulnerabilidad desconocida públicamente.

🔗 Referencia técnica: MITRE CVE Database

03. 🧬 KILL CHAIN

Bug → Discovery → Exploit → Weaponization → Delivery → Execution → Persistence → Detection → Patch

🔗 Concepto relacionado: Cyber Kill Chain Model

04. ⚙ TIPOS DE ZERO-DAY

- Memory Corruption
- Browser Exploits
- Privilege Escalation
- RCE (Remote Code Execution)
- 0-click exploits

🔗 Exploit research: Exploit Database

05. 💰 ECONOMÍA DEL ZERO-DAY

Un zero-day puede valer millones dependiendo del impacto.

Browser exploit: $100k–$500k
Mobile chain: $1M+
0-click exploit: $2M–$10M+

🔗 Mercado legal: Zerodium (Bug bounty platform)

06. 🧠 ARQUITECTURA DE ATAQUE

Recon → Delivery → Exploit → Sandbox Escape → Privilege Escalation → Persistence → C2 → Exfiltration

07. 🛡 DEFENSA MODERNA

- EDR / XDR behavioral analysis
- Sandboxing
- Least privilege
- Memory protection (ASLR, DEP)
- Patch management

🔗 Seguridad defensiva: Microsoft Security Guide

08. 🧩 EXPLOIT CHAIN

Un ataque moderno combina múltiples bugs:

1. Information Leak
2. Memory Corruption
3. Sandbox Escape
4. Privilege Escalation

09. 🔬 PATCH DIFFING

Técnica que compara versiones antes y después de un parche para descubrir la vulnerabilidad original.

🔗 Investigación: USENIX Security Research
