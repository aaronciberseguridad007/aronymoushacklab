METASPLOIT

¿Qué es Metasploit?




Metasploit Framework es una plataforma avanzada de ciberseguridad utilizada para pruebas de penetración (pentesting). Permite identificar, explotar y validar vulnerabilidades en sistemas y aplicaciones.

Es ampliamente utilizada en hacking ético para simular ataques reales como ejecución remota de código, explotación de servicios vulnerables y pruebas de seguridad en redes corporativas.

Ejemplo de uso de Metasploit




Metasploit permite analizar servicios vulnerables como SMB, FTP o HTTP en sistemas desactualizados para comprobar si pueden ser explotados.

Un pentester puede usar módulos de explotación para obtener una sesión remota y evaluar el impacto real de la vulnerabilidad en un entorno controlado.

Metasploit - Comandos esenciales (MSFConsole)


🟢 Inicio y sistema


msfconsole → Iniciar Metasploit

version → Ver versión

help → Ayuda general

exit → Salir

banner → Cambiar banner


🔎 Búsqueda de módulos


search exploit → Buscar exploits

search type:auxiliary → Buscar módulos auxiliares

search platform:linux → Filtrar por sistema

search name:samba → Buscar por nombre


⚙️ Uso de módulos


use exploit/... → Seleccionar exploit

show options → Ver opciones del módulo

show payloads → Ver payloads disponibles

show targets → Ver objetivos soportados


🎯 Configuración


set RHOSTS → IP objetivo

set RPORT → Puerto

set LHOST → IP atacante

set LPORT → Puerto atacante

set PAYLOAD → Payload

unset → Quitar valor


💥 Ejecución


exploit → Ejecutar exploit

run → Ejecutar módulo

check → Verificar vulnerabilidad


🧠 Sesiones


sessions -l → Listar sesiones

sessions -i ID → Entrar a sesión

background → Dejar sesión en segundo plano


🗄️ Base de datos


db_status → Estado DB

hosts → Hosts detectados

services → Servicios detectados

vulns → Vulnerabilidades

workspace → Gestionar proyectos


🧰 Auxiliares


use auxiliary/scanner/... → Scanners

use auxiliary/dos/... → DoS tests

use auxiliary/gather/... → Recolección info


⚡ Post-explotación


sysinfo → Info del sistema

getuid → Usuario actual

ps → Procesos

shell → Shell del sistema

hashdump → Hashes (si permitido)


🔐 Payloads (ejemplos)

windows/meterpreter/reverse_tcp

linux/x64/meterpreter/reverse_tcp

php/meterpreter/reverse_tcp
